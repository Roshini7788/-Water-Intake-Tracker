# 💧 Water Tracker

A Flutter mobile application designed to help users monitor their daily water intake and stay on track with their hydration goals.

## Features

* Record daily water intake
* Quick-add options for common quantities
* Set and update a daily hydration goal
* View progress using a progress bar
* Reset daily water intake
* Store data locally using SharedPreferences

## Technologies

* Flutter
* Dart
* SharedPreferences
* Material Design

## Objective

The application provides a simple and convenient way for users to track their water consumption and maintain healthy hydration habits.

## Getting Started

Run the following commands after cloning the repository:

```bash
flutter pub get
flutter run
```
